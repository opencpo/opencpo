# Changelog

## v1.0.0 — April 2026

### Initial Public Release

- **OpenCPO Core** — OCPP 1.6 + 2.0.1 Central System with zero trust networking
- **OpenCPO Admin** — CPO admin dashboard with skin gallery
- **OpenCPO Charge** — Driver-facing PWA with skinnable themes
- **OpenCPO Bastion** — Raspberry Pi site controller
- **OpenCPO Farm** — Virtual charger simulator
- **OpenCPO Tester** — OCPP compliance test suite
- **OpenCPO Profiles** — Charger compatibility profiles

### Highlights
- Built-in PKI (Root CA, Sub-CA, MO Sub-CA)
- Mutual TLS on all device connections
- Tailscale/WireGuard mesh VPN integration
- ISO 15118 Plug & Charge foundations
- 5 community skins + Google Stitch skin converter
- Apache 2.0 licensed
